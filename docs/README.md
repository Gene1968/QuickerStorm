# quickerSTORM — documentation for humans and AI

This folder holds **product context, conventions, planning artifacts, prompts, ADRs, and session logs** for quickerSTORM. It follows the same layout as the company **AI-Assisted Development** guide ([`../ai-assisted-workflow/docs/main-guide.md`](../ai-assisted-workflow/docs/main-guide.md) §2.4), but everything lives **in this repository** under `docs/`.

| Path (under `docs/`) | Purpose |
| --- | --- |
| **`PROJECT_BRIEF.md`** | Living product and technical anchors |
| **`CONVENTIONS.md`** | Style, naming, git, AI workflow |
| **`CONTEXT.md`** | Stack summary, key composables, Railway, presence warning |
| **`VIDEOCONF_PLAN.md`** | Jitsi / Calendar phases and env vars |
| **`SUPABASE_BACKEND_PLAN.md`** | Supabase backend design notes (historical — migration complete) |
| **`tech-debt.md`** | Known shortcuts to revisit |
| **`prompts/`** | Reusable prompt templates (`_scaffold.md`, …) |
| **`planning/docs/`** | PRD / TDD / implementation plans when you need formal deliverables |
| **`progress/reports/`** | Phase completion reports |
| **`adr/`** | Architecture Decision Records (`NNNN-title.md`) |
| **`ai-sessions/`** | Per-session logs (`YYYY-MM-DD-topic.md`) |

Repo root keeps **`CLAUDE.md`** (tooling entry point), **`README.md`**, **`TODO.md`**, and **`CHANGELOG.md`**.
